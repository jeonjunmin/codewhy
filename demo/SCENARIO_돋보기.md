# 돋보기 시연 시나리오 — "커밋 메시지는 거짓말, 코드는 진실"

> **한 줄 컨셉:** 개발자가 해외 결제 수수료를 몰래 도입해놓고 커밋 메시지엔 "띄어쓰기 수정"이라 적었다.
> `git blame`은 그 거짓말을 그대로 보여주지만, **CodeWhy 돋보기는 실제 diff를 읽어 진짜 변경을 알려준다.**

이 시나리오는 돋보기의 가장 강력한 특징 — **커밋 메시지를 맹신하지 않고 실제 코드 변경(diff)을 근거로 설명한다** — 을 정면으로 보여줍니다.

---

## 0. 준비된 데이터 (이미 demo/magnifier 브랜치에 커밋됨)

분석 대상 파일: [`demo/checkout.py`](checkout.py) — 결제 수수료 계산 모듈.

| 순서 | 메시지 | 실제로 바뀐 것 |
|---|---|---|
| ① | `feat: 결제 수수료 계산 모듈 추가` | 파일 생성, 수수료율 **0%** |
| ② | `#57 결제 완료 화면 안내 문구 띄어쓰기 수정` ⚠️**거짓말** | `calculate_fee` 에 **해외 결제 3% 수수료 도입** (`0.0` → `0.03 if order.is_overseas`) |

→ **23번째 줄** `return round(order.amount * (0.03 if order.is_overseas else 0.0))` 이 시연의 주인공입니다.
이 줄을 `git blame` 하면 ②번 커밋(`#57 ... 띄어쓰기 수정`)이 잡힙니다 — **메시지만 보면 그냥 오타 수정처럼 보입니다.**

## 2. 시연 대본 (약 2분)

### ① 거짓말을 먼저 보여준다 (git blame의 한계)

> **멘트:** "이 줄, 해외 결제에 3% 수수료를 매기는 코드입니다. 누가 왜 넣었을까요?
> 기존 도구로 먼저 확인해 보겠습니다."

`화면` 23번째 줄 위에서 **마우스 호버 → GitLens/blame 표시** (또는 `git blame`)
→ **"#57 결제 완료 화면 안내 문구 띄어쓰기 수정"** 이 뜬다.

> **멘트:** "'띄어쓰기 수정'이라고 적혀 있네요. 그런데 이게 정말 띄어쓰기였을까요?
> **커밋 메시지는 사람이 손으로 적는 거라, 틀리거나 거짓일 수 있습니다.**
> 이 말을 그대로 믿으면 '아 사소한 수정이구나' 하고 그냥 넘어갑니다 — 그게 함정입니다."

### ② 돋보기로 진실을 꺼낸다

`화면` 23번째 줄 선택 → **우클릭 → `CodeWhy: 이 코드, 왜 바꿨어?`**

사이드바에 나타나는 것:

- **🔍 변경 사유 (콜아웃):** 커밋 메시지가 아니라 **실제 diff + 연관 이슈 #57**를 근거로,
  "이 줄은 해외 결제 시 **3% 수수료를 적용**하도록 바꾼 코드입니다" 류의 설명이 스트리밍으로 타이핑됨.
- **📎 출처:** Issue #57 배지
- **🕑 라인 수정 이력:** ②번 항목의 타이틀이 원본 메시지("띄어쓰기 수정")가 아니라
  **실제 변경 기준으로 교정**되어 "결제 수수료 계산 로직 변경" 같은 제목으로 바뀐다.

> **멘트:** "보세요. **커밋 메시지엔 '띄어쓰기 수정'이라고 적혀 있었지만**, CodeWhy는 그 말을 믿지 않았습니다.
> 실제 코드 변경(diff)을 직접 읽어서 — **`calculate_fee` 함수에 해외 결제 3% 수수료가 새로 생긴 것**임을 짚어냅니다.
> 게다가 연결된 기획 이슈(#57)까지 찾아, **'왜' 3%가 됐는지**까지 설명합니다.
> 즉, **거짓말하는 커밋 메시지 앞에서도 진실을 알려주는 도구**입니다."

## 3. 이 시연이 증명하는 것 (심사위원 어필)

- **돋보기는 커밋 메시지를 신뢰하지 않는다.** `git blame`이 그대로 보여주는 거짓 메시지와 달리,
  실제 `git show -p` diff와 +/-줄 수, 바뀐 함수명(`changedSymbols = calculate_fee`)을 근거로 삼는다.
- **두 군데에서 동시에 거짓을 바로잡는다:**
  1. 라인 수정 이력 **타이틀 교정** — 순수 git 데이터만으로 작동 (백엔드만 있으면 됨, GitHub 불필요)
  2. 콜아웃 **변경 사유 설명** — diff + 연관 이슈(#57)로 진짜 의도까지 복원
- **"주석/메시지가 거짓말하는 경우가 정보가 없는 것보다 위험하다"** (발표 슬라이드 2의 메시지)를 라이브로 입증.

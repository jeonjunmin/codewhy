# 쿠폰 할인 정산 적용 기획서

- **문서버전:** v1.1
- **작성:** 마케팅팀 / 결제정산 협업
- **관련 이슈:** #59
- **상태:** 확정

## 1. 목적
프로모션 쿠폰을 정산 단계에서 일관되게 반영해, 호출부마다 제각각이던 할인 계산을 표준화한다.

## 2. 쿠폰 정의
- `coupon_rate`: 0.0 ~ 1.0 사이 실수 (예: 0.2 = 20% 할인)
- 정액 쿠폰은 본 기획 범위 밖(후속 과제). 본 문서는 **정률 할인**만 다룬다.

## 3. 적용 대상 금액
- 쿠폰은 **공급가(수수료 포함 청구액)** 에 적용한다.
- 단, **부가세(VAT) 과세 기준에는 영향을 주지 않는다.**
  → VAT는 항상 **할인 전 공급가** 기준으로 계산한다. (부가세 정책서 2항, 이슈 #60/#62와 직접 연결)

## 4. 반올림 정책
- 할인 후 금액은 **원 단위 반올림**(round) 한다.
- 0원 미만으로 떨어지지 않도록 한다(음수 방지는 #58에서 별도 처리).

## 5. 적용 순서(중요)
정산 단계의 정식 순서는 다음과 같다. 이 순서를 어기면 세금 과소·과대 계산이 발생한다.

1. 공급가 확정 (수수료 포함) — `final_charge`
2. **VAT 계산** — 할인 전 공급가 기준 — `vat`
3. 쿠폰 할인 적용 — `apply_coupon`
4. 최종 정산액 = 할인가 + VAT

> 본 순서가 코드에서 어긋나 발생한 결함이 이슈 #62이며, 구조적 해결은 #63(파이프라인 재작성)에서 이뤄졌다.
